# Quaternius character assets

These web assets are generated from the **Ultimate Modular Men** and **Ultimate Modular Women** character packs by [Quaternius](https://quaternius.com/). The eight character GLBs contain a rigged mesh and skeleton without animations; `animations.glb` contains the five shared clips `Idle`, `Idle_Neutral`, `Walk`, `Run`, and `Wave` without meshes or skins.

The original packs are released under the [CC0 1.0 Universal Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/). Source ZIPs remain outside this repository and can be converted with `npm run build:characters`.

The `License.txt` bundled in the women pack incorrectly labels that archive as "Ultimate Modular Males". It is nevertheless the license supplied with the Ultimate Modular Women source archive and declares the same CC0 1.0 terms.
